# dsh-annotations

![选中文字后出现「添加到对话」入口](assets/annotation-entry.webp)

在 DeepSeek Harness 中还原 Codex 原生的「添加到对话」交互。选中助手回复中的文字，点击「添加到对话」，即可把这段内容带入接下来的提问。

- **添加注释**：可以补充评论，也可以只保存所选原文。原文保持高亮，末端显示编号标记。
- **集中查看**：输入框里的「N 条注释」集中展示注释。将鼠标移到胶囊上可预览、编辑或删除；点击原文旁的编号也可编辑。
- **带着上下文提问**：发送消息时，注释随问题一起提供给助手。发出后仍可在消息旁查看。

文案与外观跟随 DeepSeek Harness 的语言和明暗设置。
